## 简介

函数是注册在目录中的一段逻辑，使引擎能够查找，人员能够
对其进行治理。注册函数将其置于与表相同的层级结构中，具有名称、所有者、标签和
权限。

Gravitino 存储定义而非执行。函数是否运行以及如何运行，是
读取该函数的引擎需要回答的问题。

## 快速入门

**1. 打开目录。** 函数存在于模式中，与其通常操作的表位于同一位置。参见
[目录与模式](./catalogs-and-schemas.md)。

**2. 注册函数。** 注册通过 API 而非 UI 完成。函数
需要名称、类型和至少一个定义：参数列表、返回类型，以及
SQL、Python 或 Java 的实现。

**3. 在引擎中使用。** 通过 Gravitino 读取的引擎按名称解析函数。

## 函数模型

### 函数类型

| 类型        | 返回值                                            |
|-------------|----------------------------------------------------|
| `SCALAR`    | 每行一个值                                  |
| `AGGREGATE` | 每组一个值                                |
| `TABLE`     | 一组行，用于表值操作         |

注册函数时声明类型，类型告知引擎如何调用。

### 确定性

函数被标记为确定性或非确定性。确定性函数对相同的
参数每次返回相同结果，使引擎可以缓存、重排或消除对其的调用。将
非确定性函数标记为确定性，例如读取时钟或随机源的函数，会导致
引擎以改变结果的方式进行优化。

Gravitino 记录该标记但不验证。

### 定义与实现

函数下有两个层级。

定义是重载 (overload)：一个参数列表和一个返回类型。具有多个
定义的函数是同名函数接受不同参数，正如 `round(x)` 和 `round(x, digits)`
在大多数引擎中是一个函数。

实现是定义在特定引擎中的表达方式。每个实现声明一种语言和
一个运行时，因此一个定义可以携带 Trino 的 SQL 版本和 Spark 的 Python 版本，
各引擎使用可执行的版本。

| 语言 | 携带                                          |
|----------|--------------------------------------------------|
| `SQL`    | 函数体的 SQL 文本                |
| `PYTHON` | 处理器入口点，以及可选的内联代码 |
| `JAVA`   | 类名                                     |

运行时为 `SPARK` 和 `TRINO`。Java 和 Python 实现还可以携带资源，例如
运行时需要加载的 jar 或包。

## 在 UI 中使用函数

打开模式会列出其中的函数，选择一个函数会显示其类型、确定性标记、
参数和定义。

UI 显示函数但不注册函数。注册、修改和删除函数
均通过 API 完成，附加标签同样通过 API，函数页面同样不显示标签。

## 权限

| 权限           | 可授权对象                           | 允许的操作                    |
|---------------------|----------------------------------------|-----------------------------------|
| `REGISTER_FUNCTION` | Metalake、目录、模式或函数 | 注册函数             |
| `EXECUTE_FUNCTION`  | Metalake、目录、模式或函数 | 从引擎调用函数 |
| `MODIFY_FUNCTION`   | Metalake、目录、模式或函数 | 修改已注册的函数    |

在更广范围授权涵盖其下所有对象。删除函数仅限
Metalake 所有者和对象所有者。

## 使用 API

函数可通过 REST 以及 Java 和 Python
客户端进行注册、列出、修改和删除。端点、负载结构和示例参见
[管理用户定义函数](./manage-user-defined-function-using-gravitino.md)。
